# Три русла · Татар.Бу

Мобильная PvE-дуэль на PixiJS 8: Су анасы, Керемль, Шурале и Сююмбике. Можно независимо выбрать любого хранителя на обе стороны, включая зеркальные дуэли. Все 40 оригинальных спрайтов используются: idle, attack, cast, hit, defeat в ракурсах front/back.

## Запуск

```sh
npm install
npm run dev
```

Открыть адрес Local из вывода Vite. На телефоне в той же Wi-Fi-сети — адрес Network. Сборка: `npm run build`, просмотр сборки: `npm run preview`.

## Управление

- Нажмите на русло или на кнопки Ⅰ / Ⅱ / Ⅲ.
- Два умения — кнопки снизу. Автоатака срабатывает на одном русле с врагом.
- Клавиатура: 1 / 2 / 3 или стрелки — движение, Q / E — умения, пробел / Esc — пауза.
- Под портретами выбираются свой хранитель и соперник. ⇄ меняет стороны. В бою: пауза → «Поменять героев · новый бой».
- ♪ включает необязательные ретро-звуки.
- Атлас показывает все позы в обоих ракурсах.

## Правила

Бой до 90 секунд. Телеграфы отмечают опасное русло и время до удара. Удержание запрещает движение, но не умения. Закрытые ворота не мешают выходу, но запрещают вход. По истечении времени сравнивается доля оставшегося здоровья; при равенстве — ничья. При сворачивании страницы бой приостанавливается; возвращение требует нажатия «Продолжить».

## Ассеты

Игра напрямую загружает оригинальные PNG из `su_anasy/{front,back}`, `kremlin/{front,back}`, `shurale/{front,back}` и `syuyumbike/{front,back}`. Архивы `_source` и уменьшенные копии в `assets/characters/` не используются. Предварительного уменьшения нет. На арене спрайт занимает 128 логических пикселей, рендер учитывает плотность экрана до 3×. Для замены обновите исходный PNG.

## Код

- `src/engine.js` — симуляция, умения, бот, статусы и события, без зависимости от рендера.
- `src/renderer.js` — PixiJS, спрайты, позы, эффекты, мобильная арена.
- `src/main.js` — интерфейс, смена стороны, меню, пауза, звук.
- `docs/BATTLE_ANIMATIONS.md` — анимационные сценарии, баланс и контракт событий.

## Проверка

```sh
npm test
npm run build
npm run test:browser
```

Браузерные тесты требуют dev-сервера на 5173 и Chrome (путь в playwright.config.js).

## Объём

Готов локальный тренировочный бой с четырьмя героями и восемью умениями из ТЗ. Нет сервера, NFC-встреч, постоянной коллекции, валютных наград или PvP. Серверная пауза и атомарная выдача персонажей требуют отдельного backend; клиентская тренировка не имитирует эти гарантии.

Документация PixiJS: [Application](https://pixijs.com/8.x/guides/components/application), [Textures](https://pixijs.com/8.x/guides/components/textures).
